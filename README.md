# 🚀 BioNovaX

## NASA Space Biology Knowledge Engine & RAG Chatbot

BioNovaX is an intelligent research platform developed by **BioNova Family** for exploring, analyzing, and understanding NASA Space Biology publications.

The platform combines:

- Online scientific literature extraction from NCBI PubMed Central
- AI-powered abstractive summarization
- Space Biology entity extraction
- TF-IDF keyword analysis
- Interactive knowledge graph visualization
- Scientific dataset identifier extraction
- Retrieval-Augmented Generation (RAG)
- Local open-source Large Language Models

BioNovaX is designed to help researchers, students, managers, and mission planners discover scientific relationships, summarize research findings, and identify potential knowledge gaps in Space Biology literature.

---

## ✨ Main Components

BioNovaX consists of two Streamlit applications:

1. **NASA Space Biology Knowledge Engine** — `app.py`
2. **NASA Space Biology RAG Chatbot** — `chatbot.py`

The main dashboard can open the chatbot inside an interactive popup window.
